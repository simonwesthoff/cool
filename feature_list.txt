1. Google/Apple authentication and login. Users shall be able to login with their google or apple account. Other authentication methods are not necessary as of now.
2. User Roles. There are 2 possible user roles: Coach and Athlete. Coaches can train several athletes. Coaches can also train themselves. User roles are not global, but per project. Athletes are usually invited with a link by their coaches. So the UI flows look like this: A coach adds a new athlete and then clicks an "invite" button, which copies an invitation URL that he can send to his athlete. The athlete clicks on the invitation link, which opens the web app. After authentication, the athlete's authenticated profile is linked with the athlete entity that the coach created. If a new user opens the app without an inviation link, then there's 2 buttons: "Start as Coach" and "Start as Athlete". If the athlete button is clicked, the user is asked to enter an invitation link from the coach.
3. Athlete setup. This is from the perspective of a coach. A coach can add a new athlete. Athletes have a name, date of birth, gender, start date of their weightlifting career, height, a profile picture and a mail address. This data is considered the basic data. The coach has to enter this data when creating a new athlete. Except for the mail address and profile picture, which shall be inferred from their authentication, if possible. This data usually stays the same, but the coach or athlete shall be able to update it later as well. On creation, only the name is mandatory. The rest can be filled in later by either the coach or the athlete. When a coach creates the athlete with at least the name, there shall be a button to invite the athlete, which creates the athlete in the data model and shows a screen that displays the invitation link, that the coach can send to an athlete.
4. Athelete overview. This is from the perspective of a coach. When logged in as a coach, the main screen of the app is the athlete overview. Here, a list of all athletes the coach coaches is shown with name and profile picture of each athelte. When one of the atheltes is clicked, then the athlete's details screen is opened.
5. Athelte details. The athelte details screen has 3 section: The header on the top, which shows the picture and name of the athlete. Clicking on it navigates to the athlete basic data overview. Below is the section for the curent macro cycle, which shows a time based chart of the intensity for snatch and clean and jerk exercises as well as a marker where we are in the cycle and the goal values for the training cycle for the snatch and the clen and jerk. Clicking on it navigates to the macro cycle view. The last section is dedicated to the current training week. It shows a concise version of the current week's training plan and a button to plan the next week. Clicking on the current week navigates to the current week's plan view. Only the coach sees the button to plan the next week. Clicking on it opens a view to plan the next week in a dedicated screen. If the macro cycle or the current week is not yet set up, then a placeholder the same size is shown, which prompts to set it up first. The placeholder for the macro cycle navigates to the macro cycle planning view and the placeholder for the week's plan navigates to the next week's planning view.
6. Athlete basic data overview. Here the basic data of the athlete can be seen and edited by both coach and athlete.
7. Macro cycle view. Includes current personal bests in snatch and clean and jerk, goals for snatch, clean and jerk, current and target body weight, optinally the current body fat and muscle mass percentages, a free text about current deficites, current and chronic injuries and illnesses, the beginning and duration of the macro cycle, the date and type of the competition of the main competition and the initial value in percent of the max values of the cycle. All of this data is considered the macro cycles base data. It's editable by the coach only. The most important information is a chart about the weekly projected progress of the macro cycle. This is the macro cycle chart. It shows time on the x-axis from start to end of the macro cycle. It draws the curve of intensity as well as the volume for each week. Intensity is the percentage of the maximum value for each week in percent. A macro cycle is devided into meso cycles. There are 3: Grundlagenphase, Aufbauphase and Leistungsausprägungsphase. The weeks in the chart shall be colored to reflect the phase. Each week can be a high, medium or low week. The chart shall also mark each week accordingly.
8. Macro cycle planning view. First all the macro cycle's base data is filled in. Then on a follow up screen, the macro cycle chart is drawn and each data point for intensity has a handle that can be dragged up or down. The handle can be moved up or down by 5%. Raising it up results in the week being marked as high. Letting it as is marks the week as medium. Dragging it down marks it as low. After this is done, the next screen let's the coach select the exercises for each meso cycle. Excercises are chosen from the catalog. Once this is done, the macro cycle is planned.
