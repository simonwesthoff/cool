# Exercise catalog: English names (for review)

German names come from `Trainingsmittelkatalog.csv` (with the agreed typo
fixes). English names are proposals; entries marked **?** are the ones I am
least sure about. The German UI shows the German names, the English UI the
English names.

## Catalog columns

| German column | English name in the app |
|---|---|
| Komplex | Exercise group |
| Nr. | No. (catalog number) |
| Bezeichnung | Exercise |
| Bestwert (% vom Reiß-/Stoß Max.) | Best value (% of snatch / clean & jerk max) |
| Max. Wochen Mittleres Hantelgewicht (MHG) | Max. weekly average weight (%) |
| Minimale Wdh / Maximale Wdh | Min. / max. reps per set |
| Reiß-/Stoßübung | Reference lift (snatch / clean & jerk) |
| min Wochen Wdh / max Wochen Wdh | Min. / max. reps per week |
| Kommentar | Comment |
