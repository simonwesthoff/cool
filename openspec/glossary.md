# Glossary

Domain terms for the weightlifting coaching app.

## Conventions

- **Specs and other OpenSpec artifacts** use the German term, followed by the
  English name in parentheses the first time it appears in a document,
  e.g. "Makrozyklus (macrocycle)".
- **Code** (identifiers, database tables, API routes) uses the English name only,
  e.g. `macrocycle`.
- **UI** shows the German term in the German locale and the English name in the
  English locale.
- New terms are added here in the same change that introduces them.

## Training

| German | Abbreviation | English | Definition |
|---|---|---|---|
| Trainingsmittelkatalog | TMK | Exercise catalog | The set of exercises available for planning, based on a German weightlifting training catalog. Defined in its own spec. |
| Makrozyklus | MAZ| Macro cycle | Training cycle that consists of several mesocycles. Can take up to a year. Usually ends with the main competition. |
| Mesozyklus | MEZ | Meso cycle | Each mesocycle has its focus. Usually takes 2-8 weeks. |
| Grundlagenphase | GLP | General preparation block | First MEZ in a MAZ. Focus on Hypertrophy. |
| Aufbauphase | ABP | Special preparation block | Second MEZ in a MAZ. Focus on Transferring abilities to competition excercises. |
| Leistungsausprägungsphase | LAP | Competition preparation block | Third MEZ in a MAZ. Focus on high weight competition lifts. |
| Unmittelbare Wettkampfvorbereitung | UWK | Taper | Sometimes part of the LAP. Lower intensity to reduce fatigue right before the competition. |
| Übergangsphase | - | Transition block | Phase after the competition to cure injuries. No special training. |
| Mikrozyklus | MIZ | Micro cycle | Usually a week of training. |
| Traingseinheit | TE | Training | Unit of training. Can be up to 3 times a day. |
| Traingsübung | TÜ | Excercise | Training excercise from the TMK. |
